# Existing design tokens

These are the tokens currently defined in `src/app/globals.css`. Use the existing names as they are.

## Color tokens

- `background` - used as the base site background color.
- `foreground` - used for primary text on dark surfaces.
- `panel` - used for darker panel surfaces.
- `panel-soft` - used for slightly softer panel surfaces.
- `line` - used for subtle borders and dividers.
- `line-strong` - used for stronger border contrast when needed.
- `lime` - used for the bright lime accent and highlight treatment.
- `pink` - used for the pink accent and signal treatment.
- `text-soft` - used for lower emphasis text and labels.

## Radius tokens

- `radius-panel` - used for compact panel corners.
- `radius-button` - used for buttons and other small actions.
- `radius-chip` - used for tag chips and small labels.
- `radius-resident` - used for resident and guestbook cards.

## Current usage

- The site uses the dark background and foreground tokens as the main page contrast pair.
- Panel tokens support the cards and shell surfaces used across the page.
- Line tokens support thin borders, section dividers, and subtle structural rules.
- Lime and pink are reserved for accents, highlights, and signal moments.
- Radius tokens keep the controls and cards visually consistent without introducing new corner styles.
